# Custom Hero Survival — K Edition

Forge your hero with powerful skills and crafted items, battle relentless enemy
waves, and outlast your rivals in this custom map for Warcraft III.

Created by **Kajimaru, YakumoRan, ZiHeLL, and Aduxxor**.

## Install the map

Each public release contains only the normal `.w3x` map. Internal Test maps are
kept private and are never distributed here.

Put approved official maps in `Warcraft III/Maps/Download`. Keep normal candidates
in `Download/Game Builds`. Prereleases are candidates, not an announcement of
completed online validation. Use an official release for public hosting.

Target graphics modes are Classic, Reforged/HD, and Definitive Edition in the
current Warcraft III client. Immediate online disconnections have been reported
and remain under investigation. K1.0.2 addresses Summon Tech purchases; it does
not claim to resolve those disconnections.

## About this repository

This public repository hosts downloads and English changelogs. Development code
and history are maintained in a separate private repository. The project is not
being published as open source through this repository.

When reporting a problem, include the exact map version and variant, what happened,
and the steps that led to it. Replays can help distinguish gameplay issues from
connection failures.
